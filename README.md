# LitePack

Turn a heavy video lesson into a tiny offline study pack (transcript, board images, audio and a quiz) in the learner's language.

**Status:** in development for [AccessED Hacks](https://accessed-hacks.devpost.com/) (build window Oct 17 – Nov 20, 2026). No pre-existing work; see the commit history.

The demo link, setup steps, limitations and credits will be added here as the project is built.
